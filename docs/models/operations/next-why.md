# NextWhy

Why this person has not gone out yet, as the sender itself answers it. A block on the account outranks the place in line.

## Example Usage

```typescript
import { NextWhy } from "bereach/models/operations";

let value: NextWhy = {
  status: "window",
  detail: "<value>",
  clearsItself: true,
  fixUrl: "https://athletic-cash.org",
  kind: "<value>",
  opensAt: "<value>",
};
```
