# Keywords

Roles to narrow to, written the way people write them on their own profile; a person holding any one of them counts. One role as a string; several as an array, or one string with the roles separated by commas, at most 3. A title that itself holds a comma goes in an array.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `string[]`

```typescript
const value: string[] = [
  "<value 1>",
  "<value 2>",
];
```
