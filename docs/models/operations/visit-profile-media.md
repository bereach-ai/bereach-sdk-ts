# VisitProfileMedia

What the post carries besides its words: pictures, a video, a document (carousel) with its PDF and pages, or an article. Absent on a post of words alone, a poll or an event.

## Example Usage

```typescript
import { VisitProfileMedia } from "bereach/models/operations";

let value: VisitProfileMedia = {
  type: "video",
  urls: [
    "<value 1>",
  ],
};
```
