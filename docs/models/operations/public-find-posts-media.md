# PublicFindPostsMedia

What the post carries besides its words: pictures, a video, a document (carousel) with its PDF and first pages, or an article. Absent on a post of words alone, and on a post this search read without it.

## Example Usage

```typescript
import { PublicFindPostsMedia } from "bereach/models/operations";

let value: PublicFindPostsMedia = {
  type: "article",
  urls: [
    "<value 1>",
    "<value 2>",
  ],
};
```
