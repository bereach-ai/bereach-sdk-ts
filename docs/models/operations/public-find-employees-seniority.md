# PublicFindEmployeesSeniority

Levels to keep, such as head, director, vp, cxo or owner: only people whose own title at this company is at one of them.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `string[]`

```typescript
const value: string[] = [
  "<value 1>",
  "<value 2>",
];
```
