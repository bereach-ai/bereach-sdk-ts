# CollectEngagersSave

keep (the default) saves every person read into the list; skip reads them without saving anyone, to choose first: the people are then in this answer only, every one of them, and the chosen ones are saved afterwards by reading their profiles.

## Example Usage

```typescript
import { CollectEngagersSave } from "bereach/models/operations";

let value: CollectEngagersSave = "keep";
```

## Values

```typescript
"keep" | "skip"
```
