# CollectEngagersDetailsRateLimitExceeded

On a credits refusal, "search_workspace_window_budget" means the workspace's five-hour usage limit is reached (it resets after retryAfter); "trial_provider_cost_cap" means the trial has used the usage it includes, which starting the plan ends. Both hold only what the plan or trial includes: money added by card at upgradeUrl is not held by either and is spent at once. With neither, nothing is left to spend.


## Supported Types

### `string`

```typescript
const value: string = "<value>";
```

### `string[]`

```typescript
const value: string[] = [
  "<value 1>",
  "<value 2>",
];
```
